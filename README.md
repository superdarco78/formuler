# Studio Kanałów TV

Aplikacja IPTV na Androida (telefon, tablet, Android TV / dekoder).
Budowana automatycznie przez GitHub — gotowy plik `.apk` pojawia się w zakładce **Releases**.

## Jak pobrać gotową aplikację
1. Wejdź w zakładkę **Releases** (prawa strona repozytorium).
2. Pobierz plik **studio-kanalow-tv.apk**.
3. Wrzuć go na dekoder i zainstaluj.

## Co jest w środku (Cegła 1)
- Logowanie do serwera (dane zapisane zaszyfrowane; w aplikacji nie ma żadnych sekretów).
- Lista kanałów na żywo z serwera.
- Odtwarzanie kanału (ExoPlayer / media3).
- Połączenie przez HTTPS, konfiguracja bezpieczeństwa sieci.

Kolejne kroki: filmy, seriale, EPG, wiadomości, profile, pancerz (obfuskacja).
